Six tools, one screen each

Every tool is a single page you can read at arm's length in daylight — big numbers, one unit line, nothing else asking for attention.

Compass

True-north or magnetic heading, with the needle and the degrees in the same glance.

Level

Both bubbles — flat and edge — and the angle in degrees, so a shelf or a frame can be set alone.

Elevation

Where you are and how high, from the phone's own position, with the accuracy written beside it.

Distance

Distance and bearing to a point you pick, and the ground covered getting there.

AR range finder

The rear camera, a crosshair and the height you hold the phone at. Aim at the base of a wall and read the distance, with a ± figure that says how sure it is.

Converter

Length, area, volume, weight, temperature and speed, both directions, without leaving the app.

Updates itself, without an installer

The screen you use is a page the app holds, so a correction arrives the next time you open it.

No update button, no app store in the way. MeasureT keeps its own interface on this project's GitHub Pages address and checks for a newer copy when it starts. If there is one, it downloads it and uses it from then on.

The check is a plain request for a file. It carries nothing about you: no identifier, no reading, no location. Offline, the app simply uses the copy it already has.

What it asks for, and what it does with it

Location and the camera are the only permissions it ever asks for, and neither leaves the phone.

Location is read only while a tool that needs it is open — elevation, distance, the one-tap height reading — and stays on screen. It is not written to storage and not sent anywhere. There is no background location.

The camera is started by you for the range finder and stopped by you. No photograph is taken, nothing recorded, nothing saved.

No account, no analytics, no crash reporting, no advertising, no third-party libraries watching what you do. The full statement is in the privacy policy.
